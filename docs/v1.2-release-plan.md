# v1.2 Release Plan — Portable paths + Claude plugin

## Goals

1. **No user-facing setup scripts** — chat-only onboarding; agent auto-creates `./.resume-tailor` layout.
2. **Portable user data** — default `./.resume-tailor` or `RESUME_TAILOR_USER_DIR`; legacy `~/.claude/resume-tailor` auto-detected.
3. **Claude Code / Cowork plugin** — ZIP on GitHub Releases; marketplace manifest in repo.
4. **Browser-free PDF** — pdfkit ATS fallback when Puppeteer unavailable; pdf-parse for import.

## Design decisions (locked)

| Topic | Decision |
|--------|----------|
| User data root | `./.resume-tailor` (workspace) or `RESUME_TAILOR_USER_DIR` |
| Skill root (plugin) | `$CLAUDE_PLUGIN_DIR/skills/resume-tailor` |
| Init | **Agent-only** — `init-user-data.mjs` is internal; never documented for end users |
| Plugin ZIP | `bin/build-plugin.mjs` → `resume-tailor-plugin-v{version}.zip` on release |
| Global npx install | User data at `~/.resume-tailor` (not `~/.claude/resume-tailor`) |

## Shipped in v1.2.1

- `skill/scripts/lib/user-paths.mjs` — resolve + ensure layout
- `skill/scripts/lib/export-pdf-ats-pdfkit.mjs` — ATS pdfkit fallback
- `bin/build-plugin.mjs` — assemble plugin + ZIP
- `.claude-plugin/marketplace.json` — org marketplace source
- Chat-first auto-init in `SKILL.md` + `agent-body.tmpl`
- CI: plugin build smoke test

## Verify

npm run build:plugin && node --test test/build-plugin.test.mjs
npx @mikehenken/create-resume-tailor@1.2.1 --non-interactive --platform claude --install-location global --resume none --no-install-deps

```bash

```

## Out of scope

- Customize menu (Chat) skill upload — subagents remain Claude Code only
- Automatic migration of existing `~/.claude/resume-tailor/tailors/*` (chat migration only)
